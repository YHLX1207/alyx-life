### 额外验证：读数失败时的行为（关键）
三项都是 `[ $(命令) -op 阈值 ]` 形式。若命令无输出：
```
[ $(echo) -lt 90 ]  → rc=2  （正确失败，不会误判通过）
[ "" -lt 90 ]       → rc=2
[ -lt 90 ]          → rc=2
```
**结论：读数获取失败会被判为失败，不会静默通过。**

## 未测三项的说明（历史记录，已被上面补测覆盖）
15/16/17 都是**环境阈值类**检查，要制造失败必须先破坏环境（填满磁盘、耗尽内存、
移走 DSH 安装），代价高且影响真实系统。风险可接受：它们的逻辑很直白，
且失败时会显式报错而非静默通过。

## 意义
变异测试回答的是"**这些检查会不会永远通过**"。
一个永远通过的检查不是保障，是错觉——本会话已因此吃过三次亏
（Round 2/6/8 的"测空气"实例）。

17 项通过变异测试，意味着它们构成的是真实防线，不是装饰。
